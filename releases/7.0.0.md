# EA Explorer 7.0.0: Release 7, the documentation

Release 7 (built 18 Nov 2026; **accepted and closed 18 Nov 2026**, the owner: "Then lets accept this release and we can
move on"): **a website for EA Explorer**, inside the application and on its own, written for each kind of reader;
**a How do I page for every task**, each with a picture of the screen it is done on; and **24 printed guides**, as
PDF, to print and keep.

**Before updating:** take a backup (`.\eax backup before-7.0.0`). From 6.7.0 the update runs migration 0108 (the
version). Then `.\eax up` (it rebuilds what changed and keeps your data) and `.\eax test smoke`. To make the pictures
and the guides on your own installation: `.\eax site shots`, then `.\eax site pdfs`.

## The website (Release 7.1 and 7.7)

- **One website, served by EA Explorer and published on its own**: **Documentation** in the top menu opens it, for
  everyone, signed in or not, and the folder `services/web/public/site/<version>` can be copied anywhere (a web server,
  GitHub Pages, a file share). It works offline, search included.
- **For eight kinds of reader**: System Admins, Model Admins, Project Admins, practising architects, industry model
  makers, developers, executives and platform developers, each with a page saying what EA Explorer has for them.
- **How do I**: 281 tasks, one page each, at most six steps, each with why it matters, where it sits in TOGAF, and a
  **picture of the screen** it is done on, taken from the product itself (`eax site shots`): the tab, the dialog or
  the record the task is about, not just the screen it starts on.
- **Guides** for the topics with several tasks (making a model, restoring, merging a child model, a DR site, rotating
  secrets and more), **Concepts** (the ideas behind the work and how EA Explorer maps to TOGAF), **Integrate** (for
  developers connecting systems), **Platform** (for developers working on EA Explorer itself) and a page for **every
  report and dashboard**.
- **What the AI can do** (AI › What it can do) as tiles in plain words, each opening its How do I page.
- **System Admin › Tools › Jenkins** opens Jenkins in a new tab.

## The printed guides

- **24 guides as PDF**: an overview of EA Explorer and its roles; a guide for System Admins, Model Admins, Project
  Admins, architects, industry model makers, developers and platform developers; installing, day-to-day operations,
  tuning, upgrades, troubleshooting and security; disaster recovery, site pairing for hot-standby DR, emergencies and
  testing backups and DR; the eax command, Jenkins, AI and MCP, and Keycloak with Active Directory, Entra ID, Google or
  any OpenID Connect or SAML provider; and an example project from start to finish.
- Each has a **cover**, **About this guide** (what it is for, who it is for, how to use it), **contents with page
  numbers**, numbered chapters, page numbers on every page and bookmarks; every task with its picture.
- **Where they are**: on the website under **Printed guides**, in EA Explorer under **Documentation › Printed guides
  (PDF)**, and in the repository's **documents** folder. `eax site pdfs` makes them again from the documentation.

## Fixed

- The pictures were taken before some screens had drawn (four showed only "Loading..."): the picture taker now waits
  until the screen has drawn, and up to 15 seconds for a list that arrives late.
- Three steps named buttons by the wrong words (now **Make this the latest**, **Refine it**, **Change in Keycloak**).
