# EA Explorer 6.7.0: Release 6, secrets and certificates, sync, setup and settings

Release 6 (built 17 and 18 Nov 2026; **approved and closed 18 Nov 2026**, the owner: "ok release 6 work is approved",
"lets close entire 6x line"): **no password in clear text** inside the containers, **certificates or passwords** chosen
at the start and **rotated** when you choose, **two sites paired** for content or DR, **every set-up written down** with
your own values in the commands, **your own certificate** on the front door, **Jenkins** pipelines for every command, and
**the settings exported and imported**.

**Before updating:** take a backup (`.\eax backup before-6.7.0`). From 5.7.0 the update runs migrations 0104 to 0107
(site pairings and the sync queue: three tables; the integrity checks; the settings' safety copies: one table; the
version). Then `.\eax up` (it rebuilds what changed and keeps your data) and `.\eax test smoke`. Key and certificate
rotation stay **off** until you switch them on (System Admin › Secrets, or the first-run step *Upkeep*).

## Secrets and certificates (Release 6.0, D743 to D746, D751)

- **Every password and key is a file** under /run/secrets in its own container, never an environment variable:
  `docker inspect`, process lists and logs show none. The config file keeps only where they are.
- **Certificate mode or password mode**, chosen at `eax init` (`--certificate` or `--password`): in certificate mode
  EA Explorer runs its own small certificate authority and each service signs in to the database with its own
  certificate; `eax certs switch` moves an installation over later.
- **System Admin › Secrets**: every password, key and certificate by name (never its value), its age, its next
  rotation; rotate one, or **Rotate all** behind the maintenance page (asked first), now, at a time, or monthly or
  every three months. From the machine: `eax secrets rotate`, `eax secrets rotate --all --restart`.
- **The SQL window needs no database password** in certificate mode: your EA Explorer sign-in decides.
- **Restores and DR reset the logins**, so a backup from any date restores after the passwords have rotated.
- OpenBao and the cloud-specific deploy kinds are removed: no platform-specific code (D746).

## Site pairings and sync (Release 6.5, D749, D753)

- **System Admin › Site pairings**: pair two EA Explorer sites one way, for **content sync** (models, projects, the
  organisation's content) or **DR sync** (everything, the DR site kept read only and up to date); batches in order,
  each answered, committed by hand or by themselves; **Stop and take over** on the DR site.
- **Content promotion through git**: a model's package, a project's backup or a settings file put on any git
  repository over HTTPS, and taken back from it on another site.
- **The site's purpose** (PROD, PRE-PROD, UAT, TEST, DEV, CONTENT, DR, TRAINING) shown at the top of every screen: a
  label only.

## Setup, guided and documented (Release 6.6, D750, D757 to D772)

- **System Admin › Setup**: nineteen guides as documents (a laptop, a server, any server over SSH, a new machine,
  backups, restores, a catastrophic failure, rebuilding from a backup, a DR site, switching to DR, pairings, upgrades,
  moving machines, security, a forgotten password, your own database server, certificates, Jenkins, database checks).
  **Give your values** (the server's name, the certificate and key files, the pack folder...) and **every command is
  filled in**, for Windows or Linux and macOS, to copy, or the whole guide downloaded. Nothing runs from the page.
  The same guides: `eax setup <guide> --set KEY=VALUE`, and the files in `docs/guides`.
- **Database integrity checks**, weekly and after every restore: indexes, tables, constraints, sequences, the newest
  records; safe fixes only when you switch them on; anything that touches rows waits for a Super Admin.
- **Your own database server**: `eax setup external-db --host <server>`, tested before it is saved; EA Explorer's own
  backups still run over the network.
- **Your organisation's certificate** on the front door: uploaded on System Admin › Secrets or put in from files
  (`eax certs front install --cert <file> --key <file>`), checked, used at once with no restart, the one before kept.
- **The name people open** (`eax hostname set <name>`, or `eax init --hostname`).
- **Jenkins** (`eax jenkins up`): a pipeline for every eax command and DR tool, and admin tasks by group (start and
  stop, getting back in, certificates, backup and DR, settings, upkeep); those that change everything need the
  installation's name. Runs in Jenkins' sandbox, opening no window on Windows. Tested end to end in Release 7 (R7.8).
- **Getting an administrator back in** from the machine: `eax access reset-password|unlock|mfa-off <user>`.
- **Anything that puts the maintenance page up asks first** on the screens; `eax restart` takes down a maintenance
  page left behind.

## Settings exported and imported (Release 6.7, D755, D768)

- **System Admin › Settings › Settings import and export** (Super Admins): one file, the parts you tick (application,
  system and security settings, branding, alerts, keep-for rules, report audiences, webhooks, pairings' settings, the
  banner, the IP allow lists, the schedules). Never content, people, a password, key or certificate.
- **Import shows every difference first** (here and in the file); you tick what to take; **a safety copy** is kept
  first and **Undo** puts it back; nothing here is ever removed. A file from a newer release is refused.
- The same from the machine (`eax settings export|import|copies|undo`), from Jenkins, and through git.

## Fixed

- The restore drill takes the backup straight out of EA Explorer, signs in to the DR copy to decide, and leaves the DR
  copy running for you to look at.
- Rotate all no longer leaves a service half made again; on Windows what makes services again runs from PowerShell only.
- *Check the integrity now* no longer puts the maintenance page up.
- The self-test's runner gets the database passwords (they are files now); a stopped test runner is not an alert.
- The UI review (`eax test ui-review`) is removed.
