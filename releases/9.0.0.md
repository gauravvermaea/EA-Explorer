# EA Explorer 9.0.0: Release 9, the AI reads the documentation, themes, and the restore drill in the full test

Release 9 (built 22 Nov 2026; **accepted 22 Nov 2026**, the owner: "R9 is accepted"): your AI can now read EA
Explorer's own documentation; you can pick and make your own themes; an administrator can make someone set up their
authenticator again from the user list; and the full test ends with a real restore drill. The learning videos that
were planned here move to Release 20, the last.

**Before updating:** take a backup (`.\eax backup before-9.0.0`). The update runs migrations 0113 and 0114. Then
`.\eax clean-restart` (the compose file, the api, web and ops images changed) and `.\eax test smoke`. For the new
Jenkins jobs: `.\eax jenkins up`.

**Also in this code, not yet accepted:** Release 10, scenario planning and game theory through your AI (migration
0113, the project's Scenario planning tab and the sample in Protea build or buy). It is there to be tried; it is
accepted, and announced, as 10.0.0.

## For everyone

- **Your own look** (My look): pick from the themes your administrator offers, download a theme's CSS, upload one,
  or design your own in the theme designer (up to ten). If your administrator stops offering a theme you use, you are
  told once and given the default.
- **Your AI reads the documentation** (MCP): it can list, search and read the guides, the How do I pages, the help of
  any screen and the error codes, and hand you the printed guides, so it can answer "how do I…" from the real text.
  The AI page has a tile for it.

## For administrators

- **Set up the authenticator again** from System admin › Users: the Authenticator column shows who has one; tick
  people and choose **Set up the authenticator again…**. They are signed out, emailed, and asked for a new one at their
  next sign-in. Not for yourself (another administrator, or a Super Admin on System admin › Security), and a Super
  Admin only by another Super Admin.
- **Themes**: choose which themes people may pick, and whether they may make their own (System admin › Branding);
  see and remove people's own themes.
- **`.\eax access mfa-off --all`** switches multi-factor sign-in off for everyone (the setting, every authenticator
  and every request to set one up), and `.\eax access mfa-off <user>` no longer asks for a new one straight away. In
  Jenkins: eax-admin › Get back in › mfa-off-for-everyone.
- **`.\eax images`** checks every three months (and when you ask) whether newer images are published for what
  EA Explorer runs, and tells you.

## Testing

- **`.\eax test full`** ends with the **restore drill**: this installation backed up and shut down, a DR copy built
  beside it and restored, the smoke test on the copy, then the copy stopped (kept) and this installation started again
  and signed in to. Its card on the summary page shows the recovery time. `--no-dr` leaves it out. The full test can
  also be started from Jenkins (eax-admin › Upkeep › full-test).
- **`.\eax test jenkins`** starts every Jenkins pipeline as a probe and checks the right command reached the agent,
  without running it; it shows its progress and reports a refused pipeline at once.
- **`.\eax test commands`** runs every eax command that only reads or reports, through your own launcher, and checks
  each answers as it should.

## Known issues

- Four Jenkins pipelines (eax-admin's start and maintenance page on, off and clear) can never run: they have no CONFIRM
  field (R14.18, to be fixed in Release 14).
- Certificate mode still does not work (the API cannot open its key): Release 11.

## In one paragraph (for the GitHub release)

EA Explorer 9.0.0 lets your AI read EA Explorer's own documentation, lets people pick, download, upload and design
their own themes, lets an administrator make someone set up their authenticator again from the user list, adds
`eax access mfa-off --all` (also in Jenkins), checks for newer images every three months, and makes the full test end
with a real restore drill, with new automated tests of every Jenkins pipeline and every reading command. Take a backup,
then `.\eax clean-restart`. Scenario planning (Release 10) is in the code to try, not yet accepted.
