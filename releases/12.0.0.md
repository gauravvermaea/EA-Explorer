# EA Explorer 12.0.0: Release 12, project and model templates from TOGAF and its Series Guides (unstable)

Release 12 (built 22 and 23 Nov 2026; **closed as an unstable release on 23 Nov 2026**, the owner: "I am ready to close
the release as an unstable release", "We will fix everything in R14"). The new templates, the project plan, sprints, the
risk register, the ready-made surveys, TOGAF skills and the guides were tested by hand and accepted; the full test did
not complete on the owner's laptop (see Known issues), so this release is marked **unstable**. Every problem found is in
Release 14.

**Before updating:** take a backup (`.\eax backup before-12.0.0`). The update runs migrations 0117 to 0120, and at
start-up brings existing projects and models up to the new bases (only what each lacks; nothing already there
changes). Every image changes, so run `.\eax clean-restart`, then `.\eax test smoke`. The first start after the update
loads the industry packs into Documents, which keeps the machine busy for a while: run tests once it has finished.

## For architects

- **New project templates**: Agile architecture in sprints, Digital transformation, EA capability, Risk and security
  and Data governance, each with its own model template, and a Government model template (six model templates).
- **Eight new types** in the ArchiMate 4 and TOGAF roots, as EA Explorer extensions: Risk, Threat, Security
  Requirement, Data Domain, Quality Rule, Analytics Product, Epic and Feature. Existing models get them at start-up.
- **The project plan** (Plan › Project plan): RACI (per phase, deliverable or step, chosen at setup), approval gates on
  the phases you choose, each phase's planned dates on a time line, milestones, status reports (green, amber, red) and
  the roadmap of the working model for any period.
- **Sprints** for Agile projects (Plan › Sprints): Sprint zero, an obligatory sprint goal, the review as demo, outcome,
  retrospective and planning, and the backlog ordered the way the project chooses.
- **The risk register** (Governance › Governance log › Risks): risks with likelihood, impact, residual risk, treatment
  and controls; risks in the models that are not yet logged are listed and logged in one step.
- **Ready-made surveys** (Project Admin › Surveys and maturity): start from the maturity assessment, the business
  capability assessment and two more.
- **TOGAF skills**: your TOGAF roles and skills on My profile; the skills repository by role.
- **Live views**: a map item opens its view on the working model.
- **The TOGAF generic reference model** in the model library, described in EA Explorer's own words.

## For system administrators

- **Guides**: the Reference library lists the TOGAF Standard and Series Guides with where to read and download them,
  and gives the guides as one zip. An organisation can upload its own guides as a zip, kept with their folders in
  Documents (also offered as an optional first-time setup step).
- **Connectivity**: the heartbeat checks every connection the product depends on (24 of them: the database logins,
  Documents, Keycloak, the library, views, ops, Reports, draw.io, jobs and backup); System Admin › Tools › Heartbeat
  shows each one, and the smoke and full tests record each as a check.
- **Documents work in certificate mode** (the API can sign in to Documents' database by certificate).
- **The "not for AI use" check reads the first page of a file only** (D895): loading the industry packs takes about a
  minute instead of hours.
- **The seed makes no temporary tables** (D896): the API starts on a database that gives its migrations login connect
  rights only.

## Testing

- Browser journeys for every new screen (project plan, live maps, risk register, ready-made survey, TOGAF skills,
  guides).
- A unit test that runs over 5 minutes prints where it is, and the run carries on.

## Known issues (all in Release 14)

- **The full test did not complete on the owner's laptop** (R14.27): the unit tests read the code through Docker's share
  of the C: drive (about 26,000 file look-ups), which crawls while Documents is busy; on 23 Nov 2026 it never finished.
- **Documents runs OCR on the industry pack files** (R14.28) after a clean restart, keeping the machine busy for an hour
  or more, although the files already hold their text.
- **Live items show "none yet"** when the model has items (for example the Business Scenario Register on an Agile
  project), and the live views have no sample content (R14.29).
- **An existing project cannot be made Agile** (R14.30); only a project made from the Agile template has sprints.
- **The SQL window cannot call eax.get_entity** (R14.31): its logins may not make the temporary tables it uses.
- **The seed was never run with the production database rights before the owner's start-up** (R14.32): the tests now
  check for temporary tables, but no test runs the seed as eax_migrator on a database set up like production.
- **The laptop ran out of memory** during a clean restart (R14.33): the API restarted over and over.
- From earlier releases: `eax diag` writes an empty report (R14.23); four Jenkins pipelines can never run (R14.18);
  `test_logs_kept.py::test_backup_and_clean` depends on the order files come back from disk.
- The guides and How do I pages do not describe Release 12 yet: they are written with every other guide in Release 16.

architecture in sprints, Digital transformation, EA capability, Risk and security and Data governance (and a Government
model template), eight
new types in the root metamodels, a project plan with RACI, approval gates and a phase time line, sprints, a risk
