# The demo project

Release 5.7 (owner, 17 Nov 2026, 15:18: "Make one Mega Project ... all the data every kind should be in it so that when
i demo I have eveything in one model"; D734). On a laptop, the sample data gathers every kind of content in **one
project with its models**, and a **demo account** has them pinned.

## Signing in

**demo-super-admin**, with the laptop's sample password (`.\eax logins` prints it). A Super Admin: it sees and does
everything. Its **Recent and pinned** has the demo project and its models first.

## The project and its models

**Protea Claims Transformation 2028 (sample)**, its description starting "Demo project: every kind of content".

| Model | What it shows |
|---|---|
| Protea Insurance (demo estate) | The current state: drawn views, KPI trends, tags and gap analyses, duplicates found and merged, deliveries from other systems, an MCP clean-up copy, discovery |
| Protea claims target 2028 | The target (the project's home model), a child of the estate |
| Protea claims transition 2027 | The transition state; a merge request sent and withdrawn |
| Protea claims: partner-led (scenario) | A scenario copied from the target, with a what-if, assessed against it |
| Insurance reference model | The reference it reads from |

## What the project holds

Business Model Canvases of every kind (current, working copy with marks, clean target, scenario, comparison); customer
journeys today and 2028 with the emotion curve; key questions in every state; drawn views as evidence; uploads with
versions; an ADM iteration history; its project library; the governance log with a record of every kind in every
approval state (decisions, a decision record and a dispensation linked to elements, risk, issue, compliance and
capability assessments); the charter approved; its people, calendar, phases and steps done; a deliverable placed in the
content framework; tracking sheets; stakeholders with a discussion; standards; tasks in each status; a document sent for
sign-off; a scenario assessment.

The organisation-wide samples (surveys and maturity assessments, the enterprise library, branding themes, the
Architecture Board, the reference library, the archive, AI activity) are on their own pages, as always.
