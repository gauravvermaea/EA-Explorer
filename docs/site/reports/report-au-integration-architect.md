## What it shows

**What it gathers:** [[report-sr-06|SR-06 Interface and integration catalogue]], [[report-sr-15|SR-15 Application interaction matrix]], [[report-vp-11|VP-11 Application Cooperation view]].

## Why it matters

An audience dashboard gathers, on one page, the headline charts of the reports one kind of person usually needs, so they start from what matters to them instead of browsing the whole catalogue.

**In TOGAF terms:** Stakeholder management: each audience sees the views that address its concerns. See [[ea-explorer-and-togaf]].

## Who it is for

Integration architect.

## How to use it

Use it as the starting dashboard for the Integration architect dashboard: the reports that matter to this audience, together.

## How to read it

Each chart is described where it comes from; open the full report from the Reports tab for detail.

## Where to find it

Open a model, **Reports › Reports**, and choose **Integration architect dashboard**; it opens its dashboard for that model. Every chart can be filtered, and most rows have **Open** to go to the entity in EA Explorer. The same data is in the model's OData feed for your own tools ([[odata-feeds]]).
