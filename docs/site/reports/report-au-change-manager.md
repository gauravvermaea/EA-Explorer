## What it shows

**What it gathers:** [[report-sr-07|SR-07 Stakeholder and actor catalogue]], [[report-sr-22|SR-22 Impact analysis]], [[report-vp-23|VP-23 Project view]], [[report-vp-25|VP-25 Implementation and Migration view]], [[report-tc-02|TC-02 Stakeholder catalogue]], [[report-tc-08|TC-08 Work package and roadmap catalogue]], [[report-tm-10|TM-10 Stakeholder and concern matrix]], [[report-dr-01|DR-01 Dependencies of an entity]], [[report-gr-01|GR-01 Gap analyses]], [[report-gr-04|GR-04 Gap resolutions and work packages]].

## Why it matters

An audience dashboard gathers, on one page, the headline charts of the reports one kind of person usually needs, so they start from what matters to them instead of browsing the whole catalogue.

**In TOGAF terms:** Stakeholder management: each audience sees the views that address its concerns. See [[ea-explorer-and-togaf]].

## Who it is for

Change manager.

## How to use it

Use it as the starting dashboard for the Change manager dashboard: the reports that matter to this audience, together.

## How to read it

Each chart is described where it comes from; open the full report from the Reports tab for detail.

## Where to find it

Open a model, **Reports › Reports**, and choose **Change manager dashboard**; it opens its dashboard for that model. Every chart can be filtered, and most rows have **Open** to go to the entity in EA Explorer. The same data is in the model's OData feed for your own tools ([[odata-feeds]]).
