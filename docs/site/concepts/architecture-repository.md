## One place for the whole record

The TOGAF Standard describes an Architecture Repository: a single place holding everything the practice produces and
relies on, so that work is found, reused and trusted instead of redone. EA Explorer is built around it; the menu
**Repository & Content Framework** opens it ([[use-the-architecture-repository]]).

## Its parts

| Part | What it holds |
| --- | --- |
| Architecture Landscape | The models, by level: strategic, segment, capability, transition |
| Reference Library | Reference models and documents to reuse: foundation, common systems, industry, your own |
| Standards Information Base | The standards the organisation has chosen |
| Governance Log | Decisions, compliance assessments, capability assessments, the calendar, the portfolio |
| Architecture Capability | The practice itself: skills, maturity, organisation, the board |
| Architecture Requirements | The requirements every project raises and must meet |
