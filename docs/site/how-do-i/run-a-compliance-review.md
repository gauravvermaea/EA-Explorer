## Why do this

A compliance review, part of ADM phase G, checks that what is being built matches the architecture, principles and standards agreed. Findings become actions, and agreed exceptions become dispensations. See [[governance-and-sign-off]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** Phase G, Implementation Governance: architecture compliance review. See [[ea-explorer-and-togaf]].

**The goal:** A solution or change is checked against the architecture.

> **Before you start** You need a role on the project (Architect or higher), unless a step says otherwise.

## Steps

1. Open the project, **Governance**, **Compliance review**.
2. Name what is reviewed; answer each check.
3. Record the outcome and actions; send for sign-off.
