## Why do this

The portfolio is the leadership view of architecture work: what is running, where each project is, and which need attention. See [[kinds-of-projects]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See [[ea-explorer-and-togaf]].

**The goal:** You see every project, its phase and its health.

## Steps

1. Open **Architecture Work › My projects** (or Enterprise Repository › Project portfolio).
2. Switch between tiles and the list; filter by state.
