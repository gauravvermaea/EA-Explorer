## Why do this

The governance log is the memory of architecture decisions across projects. Reading it before deciding avoids contradicting an earlier decision without knowing it. See [[governance-and-sign-off]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** Architecture governance: the governance log. See [[ea-explorer-and-togaf]].

**The goal:** You see the organisation's decisions and their reasons.

## Steps

1. Open **Enterprise Repository › Governance Log**.
2. Filter by kind, status or project.
3. Open a record for its evidence.
