## Why do this

When a project's set-up worked well, saving it as a template lets future projects of that kind start the same way. See [[kinds-of-projects]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See [[ea-explorer-and-togaf]].

**The goal:** A project that worked becomes the start for others.

> **Before you start** You need the Library Admin role.

## Steps

1. Open **Project Admin › Wizards**, **Save a project as a template**.
2. Pick the project; name the template.
3. Confirm.
