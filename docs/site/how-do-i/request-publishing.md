## Why do this

Publishing makes a library model available to everyone, so it is approved first. Requesting it, with what changed, starts that review. See [[industry-models]].

Reference models only help if they are sound and kept up to date, so the library has its own review: promote, request, approve, publish, and withdraw when a reference is past its time.

**In TOGAF terms:** The Enterprise Continuum: moving from generic and industry architectures to your organisation's own, and back as reusable references. See [[ea-explorer-and-togaf]].

**The goal:** A library model is sent for approval to publish.

> **Before you start** You need the Model Admin role on the model.

## Steps

1. Open **Model Admin › Wizards**, **Request publishing**.
2. Pick the model; say what changed.
3. **Send**.
