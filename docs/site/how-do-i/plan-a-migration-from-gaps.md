## Why do this

The migration wizard turns a gap analysis into work packages grouped into waves, and can make transition models for the states between today and the target. See [[the-adm]].

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

**In TOGAF terms:** Phase F, Migration Planning: transition architectures and the roadmap. See [[ea-explorer-and-togaf]].

**The goal:** Gaps become work packages and transition models.

> **Before you start** You need the Model Admin role on the model.

## Steps

1. Open **Model Admin › Wizards**, **Plan the migration from gaps**.
2. Pick the gap analysis; group the gaps into work packages and waves.
3. Confirm; transition models are made if you choose.
