> **Before you start** A Discovery Admin has set up a discovery project (AI (MCP) › Enterprise discovery) with its
> target model and sources.

## Steps

1. Ask your AI assistant to run the discovery project.
2. It reads the sources (mailboxes, folders, SharePoint, Git, wikis, ticket systems, database schemas and more) and
   proposes the elements and relationships it finds, each with where it was found.
3. What it proposes is reviewed like any change. Documents marked NOT FOR AI USE are never read.
