## Why do this

A blank project lets you set up exactly what you need when no template fits, choosing the ADM phases and deliverables yourself. See [[kinds-of-projects]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See [[ea-explorer-and-togaf]].

**The goal:** A project with nothing set up, for work no template fits.

> **Before you start** You need the Project Admin or Super Admin role.

## Steps

1. Open **Project Admin › Wizards › Blank project**.
2. Fill in **Basics**, then each step you need.
3. **Review**; finish.
