## Why do this

Finishing a project says its work is done and agreed: every deliverable signed off, what was delivered written down. From then on nothing changes, so the record of what was decided and why is preserved. See [[projects-and-deliverables]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The end of an ADM cycle; phase H decides when the next begins. See [[ea-explorer-and-togaf]].

**The goal:** The project is closed and becomes part of the record.

> **Before you start** You need the Project Admin role on the project.

## Steps

1. Check every deliverable is signed off.
2. **Finish the project**: say what was delivered.
3. Confirm.
