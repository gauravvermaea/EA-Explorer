## Why do this

Projects change as they learn: a model is added, the scope narrows, new people join. Editing runs the set-up wizard again on the project as it is, so its structure stays true. See [[projects-and-deliverables]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See [[ea-explorer-and-togaf]].

**The goal:** A project's set-up matches what the project has become.

> **Before you start** You need the Project Admin or Lead Architect role.

## Steps

1. Open the project, **✎ Edit**.
2. Go to the step to change.
3. **Review**; finish.
