## Why do this

Templates set up a project for its kind: transformation, migration, rationalisation and others, each with the right phases, deliverables and models. See [[kinds-of-projects]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See [[ea-explorer-and-togaf]].

**The goal:** A project set up for its purpose from the start.

## Steps

1. Open **Project Admin › Wizards** and choose **From a project template**.
2. Choose the template.
3. Fill in **Basics**: name, purpose and description.
4. Go through the steps and **Review**; finish.
