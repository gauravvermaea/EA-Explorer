## Why do this

The base is what the project builds on: the models and the tag each is taken at. Starting from a tagged moment means the baseline does not shift under the project while others keep changing the live model. See [[versions-tags-and-merging]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The baseline the ADM phases start from, taken at a fixed point. See [[ea-explorer-and-togaf]].

**The goal:** The project starts from the right models at the right moment.

> **Before you start** You need the Project Admin or Lead Architect role.

## Steps

1. Open the project, **Plan › Base**.
2. Pick each model and the tag it is taken at.
3. **Save**.
