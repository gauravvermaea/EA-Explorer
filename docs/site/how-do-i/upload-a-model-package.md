## Why do this

A model package from this or another installation can be uploaded as a new model or over the one it came from. It is how models move between sites.

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

**In TOGAF terms:** The Architecture Landscape in the Architecture Repository: the models at strategic, segment, capability and transition levels. See [[ea-explorer-and-togaf]].

**The goal:** A model from a package is here.

> **Before you start** You need the Model Creator or Library Admin role.

## Steps

1. Open **Model Admin › Wizards** and choose **Upload a model**.
2. Choose the file (or take it from git).
3. As a new model, or over the model it came from; **Upload**.
