## Why do this

Every check-in keeps the version before it. Seeing earlier versions shows how a document developed, and any version can be made current again.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See [[ea-explorer-and-togaf]].

**The goal:** Any earlier version of a document can be read or brought back.

## Steps

1. Open the document, **Versions**.
2. Download any version; the newest is current.
3. **Make it the latest version** to go back to an earlier one.
