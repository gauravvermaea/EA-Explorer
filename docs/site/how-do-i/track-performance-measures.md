## Why do this

Performance measures show whether the architecture practice delivers: time to approve, reuse rates, standards compliance. Tracking them shows improvement and builds support. See [[architecture-repository]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The architecture capability: measuring the practice. See [[ea-explorer-and-togaf]].

**The goal:** The practice is judged by measures, over time.

## Steps

1. Open **Enterprise Repository › Performance measurement**.
2. Add a measure and its target.
3. Record values as they come.
