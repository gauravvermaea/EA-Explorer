## Why do this

The principles library is the organisation's agreed set. Keeping it current means every project starts from the same rules. See [[principles-and-standards]].

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

**In TOGAF terms:** The Preliminary phase: the organisation's architecture principles. See [[ea-explorer-and-togaf]].

**The goal:** The organisation's principles are kept in one place for every project.

> **Before you start** You need the Library Admin role.

## Steps

1. Open **Project Admin › Principles**.
2. Add or change a principle: statement, rationale, implications.
3. **Save**; projects add them from the library.
