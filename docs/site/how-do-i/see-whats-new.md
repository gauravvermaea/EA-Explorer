## Why do this

Each release brings changes people should know about: new screens, changed behaviour, fixes. What's new shows them once to each person after an update, so nobody is surprised, and the release notes keep them for anyone who looks later.

EA Explorer covers a lot of ground. A few habits (search, help on every screen, your own requests and pins) make it feel smaller and get you to your work faster.

**In TOGAF terms:** General use of the tool, across every part of the Architecture Repository. See [[ea-explorer-and-togaf]].

**The goal:** You know what changed in the release just installed.

## Steps

1. After an update, **What's new** opens once; **Got it** closes it.
2. Read any release again from **? › Release notes**.
