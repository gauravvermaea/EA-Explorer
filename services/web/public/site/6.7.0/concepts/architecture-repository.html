One place for the whole record

The TOGAF Standard describes an Architecture Repository: a single place holding everything the practice produces and relies on, so that work is found, reused and trusted instead of redone. EA Explorer is built around it; the menu Repository & Content Framework opens it (Find your way round the Architecture Repository).

Its parts

PartWhat it holds
Architecture LandscapeThe models, by level: strategic, segment, capability, transition
Reference LibraryReference models and documents to reuse: foundation, common systems, industry, your own
Standards Information BaseThe standards the organisation has chosen
Governance LogDecisions, compliance assessments, capability assessments, the calendar, the portfolio
Architecture CapabilityThe practice itself: skills, maturity, organisation, the board
Architecture RequirementsThe requirements every project raises and must meet
