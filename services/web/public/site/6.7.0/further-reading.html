EA Explorer itself

  • The EA Explorer YouTube channel ↗: short videos by role.
  • The code on GitHub ↗: the source, the releases and how to report a problem or suggest a change.

The standards it follows

  • The TOGAF Standard ↗, from The Open Group: the Architecture Development Method (ADM) that EA Explorer's projects follow, and the content metamodel its models can use.
  • ArchiMate ↗, from The Open Group: the modelling language EA Explorer's metamodel and drawn views use.
  • The Model Context Protocol ↗: how your own AI assistant talks to EA Explorer.
  • OData ↗: the feed Power BI and Excel read EA Explorer's models through.
  • OpenAPI ↗: how EA Explorer's REST API is described (its own pages are at /api/docs in every installation).

The open-source parts it is built on

  • PostgreSQL ↗: the database.
  • Keycloak ↗: sign-in, single sign-on and multi-factor sign-in.
  • Apache Superset ↗: the reports and dashboards.
  • Mayan EDMS ↗: document management in projects.
  • draw.io ↗: the drawn views.
  • Docker ↗: what every part runs in.
  • Jenkins ↗: the operations pipelines.

Every part and its licence is listed in EA Explorer itself, on System Admin › Settings › Licences.
