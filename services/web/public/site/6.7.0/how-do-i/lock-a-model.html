Lock a model

For: Model Admin

Stop changes for a while (the metamodel, the content or everything), with a reason everyone sees.

On this page
  • Why do this
  • Steps
  • Related

Why do this

Locking stops changes during a sensitive moment: a review, a merge, an audit. Unlike freezing it is temporary, and the reason is shown on the model.

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

In TOGAF terms: The Architecture Landscape in the Architecture Repository: the models at strategic, segment, capability and transition levels. See EA Explorer and the TOGAF Standard.

The goal: Nobody changes a model for a while, and everyone sees why.

Before you start You need the Model Admin role on the model.

Steps

  1. Open Model Admin › Wizards, Lock or unlock, and pick the model.
  2. Choose what to lock: the metamodel, the content or everything.
  3. Give the reason; it is shown on the model. Lock.
