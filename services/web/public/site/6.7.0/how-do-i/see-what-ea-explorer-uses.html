See the resources EA Explorer uses

For: System Admin

Memory, processor and disk over time, per service.

Why do this

Resource use over time shows when the machine is getting full and which part is responsible, before it becomes a problem. See Running the installation.

The installation is built to look after itself as far as it can, and to ask before anything risky. These tasks are the decisions it leaves to you: what to run, when, and how far to trust a change.

In TOGAF terms: Outside the method: this keeps the tool that holds the Architecture Repository running. See EA Explorer and the TOGAF Standard.

The goal: You see the memory, processor and disk each part uses over time.

Before you start You need the Super Admin or IT Admin role.

Steps

  1. Open System Admin › Footprint.
  2. Pick the period and the service.
  3. Read the trend; Sizing suggests what to change.
