See the job queue

For: System Admin

Every background job; spot stuck ones.

Why do this

Long work runs as jobs. The queue shows what is running and waiting; a job stuck for too long is recommended for clearing, and you decide. See Running the installation.

The installation is built to look after itself as far as it can, and to ask before anything risky. These tasks are the decisions it leaves to you: what to run, when, and how far to trust a change.

In TOGAF terms: Outside the method: this keeps the tool that holds the Architecture Repository running. See EA Explorer and the TOGAF Standard.

The goal: You see every background job and spot stuck ones.

Before you start You need the Super Admin or IT Admin role.

Steps

  1. Open System Admin › Jobs.
  2. Read what is running and waiting.
  3. A stuck job is recommended for clearing; you decide.
