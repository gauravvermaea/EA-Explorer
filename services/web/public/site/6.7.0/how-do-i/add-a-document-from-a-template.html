Add a document from a template

For: Project Admin, Practising architects

A deliverable started from the template library.

Why do this

Each ADM phase produces deliverables: the architecture vision, the definition document, the roadmap. Templates give them a consistent shape across projects, so readers know where to look and nothing important is forgotten. See Projects, deliverables and sign-off.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See EA Explorer and the TOGAF Standard.

The goal: A deliverable starts from the agreed template, not a blank page.

Before you start You need a role on the project (Architect or higher), unless a step says otherwise.

Steps

  1. Open the project, Template library.
  2. Look through a template library: search, open one.
  3. Add it to the project; fill it in.
