Set the application settings

For: System Admin

Organisation name, formats, defaults for everyone.

Why do this

Application settings decide what everyone sees: the organisation's name, its currency, time zone, and date and number formats. Getting them right early matters, because costs, dates and reports across every model use them.

The installation is built to look after itself as far as it can, and to ask before anything risky. These tasks are the decisions it leaves to you: what to run, when, and how far to trust a change.

In TOGAF terms: Outside the method: this keeps the tool that holds the Architecture Repository running. See EA Explorer and the TOGAF Standard.

The goal: EA Explorer speaks your organisation's language.

Before you start You need the Super Admin or IT Admin role.

Steps

  1. Open System Admin › Settings › Application settings.
  2. Change what you need.
  3. Save.
