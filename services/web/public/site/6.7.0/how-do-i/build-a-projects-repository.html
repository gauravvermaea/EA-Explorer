Build a project's repository now

For: Project Admin

Gather the project's deliverables into its Enterprise Repository view.

Why do this

Each project has its own view of the Architecture Repository: its deliverables, artifacts and building blocks in the places the TOGAF Standard puts them. Building it now refreshes that view from the latest work. See The Architecture Repository.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: The Architecture Repository, as seen by one project. See EA Explorer and the TOGAF Standard.

The goal: The project's deliverables are gathered into its repository view.

Before you start You need the Project Admin role.

Steps

  1. Open Project Admin › Wizards, Build a project's repository now.
  2. Pick the project; confirm.
  3. Open the project's Enterprise Repository tab.
