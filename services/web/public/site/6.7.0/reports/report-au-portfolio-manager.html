What it shows

What it gathers: SR-01 Application portfolio inventory, SR-18 Application TIME quadrant, SR-19 Criticality against technical health, SR-25 Rationalisation candidates, VP-21 Outcome Realization view, VP-22 Resource Map view, VP-23 Project view, VP-25 Implementation and Migration view, VP-26 Gap view, TC-07 Contract and measure catalogue, TC-08 Work package and roadmap catalogue, TM-11 Plateau and architecture matrix, GR-04 Gap resolutions and work packages, GR-05 Gap entities in the models.

Why it matters

An audience dashboard gathers, on one page, the headline charts of the reports one kind of person usually needs, so they start from what matters to them instead of browsing the whole catalogue.

In TOGAF terms: Stakeholder management: each audience sees the views that address its concerns. See EA Explorer and the TOGAF Standard.

Who it is for

Portfolio manager.

How to use it

Use it as the starting dashboard for the Portfolio manager dashboard: the reports that matter to this audience, together.

How to read it

Each chart is described where it comes from; open the full report from the Reports tab for detail.

Where to find it

Open a model, Reports › Reports, and choose Portfolio manager dashboard; it opens its dashboard for that model. Every chart can be filtered, and most rows have Open to go to the entity in EA Explorer. The same data is in the model's OData feed for your own tools (OData feeds EA Explorer publishes).
