AU-cdo Chief Data Officer dashboard

For: Practising architects, Executives

The headline view of every report a Chief Data Officer usually wants, on one page.

What it shows

What it gathers: SR-04 Data entity catalogue, SR-11 Application against data entity (CRUD), VP-03 Information Structure view, TM-06 Data entity and business function matrix, TM-07 Data security matrix.

Why it matters

An audience dashboard gathers, on one page, the headline charts of the reports one kind of person usually needs, so they start from what matters to them instead of browsing the whole catalogue.

In TOGAF terms: Stakeholder management: each audience sees the views that address its concerns. See EA Explorer and the TOGAF Standard.

Who it is for

Chief Data Officer.

How to use it

Use it as the starting dashboard for the Chief Data Officer dashboard: the reports that matter to this audience, together.

How to read it

Each chart is described where it comes from; open the full report from the Reports tab for detail.

Where to find it

Open a model, Reports › Reports, and choose Chief Data Officer dashboard; it opens its dashboard for that model. Every chart can be filtered, and most rows have Open to go to the entity in EA Explorer. The same data is in the model's OData feed for your own tools (OData feeds EA Explorer publishes).
