EA Explorer 7.9.0: Release 7.9, error codes and the error code guide

On this page

Release 7.9 (built 18 Nov 2026; accepted and closed 19 Nov 2026, the owner: "ok lets release 7.9"): every problem EA Explorer finds has an error code, the same wherever it shows, with what it means and what to do; and a guide to every code, on the website and as a printed guide.

Before updating: take a backup (.\eax backup before-7.9.0). From 7.0.0 the update runs migration 0109 (the version). Then .\eax up (it rebuilds what changed and keeps your data) and .\eax test smoke. For the new Jenkins folder: .\eax jenkins pipelines.

Error codes

  • One code per problem, of the form EAX-AREA-NNN (for example EAX-AUTH-001, sign-in down): 60 codes, each with what it means, its usual cause and what to do. A code never changes its meaning.
  • Where they show:
    • **eax status**: after the containers and the disks, every problem now, the most serious first, each with its code and what to do. eax status problems lists the problems only.
    • System Admin › Running › Health: each part that is not up shows its code and what to do.
    • System Admin › Running › Alerts: each open alert shows its code and what to do; the alert's notification and email name the code too.
    • The screens: an error message ends with its code in brackets.
    • The API: every error answer has error_code and to_do beside message, and the header X-EAX-Error-Code.
    • The logs: the API's log lines about a problem carry error_code, so they can be searched by code.
  • **eax errors**: eax errors EAX-AUTH-001 says what a code means and what to do; eax errors BAK lists an area's codes, eax errors backup searches; on its own it lists every code. It needs no containers.
  • Jenkins: a new admin folder, Status and error codes: status (the environment: containers, disks and every problem with its code), problems and error-code (put a code in CODE).

The error code guide

  • On the website: Guides › Error codes, every code by area, and two new How do I pages: **Find what an error code means and See every problem from the machine. Check the health and alerts** links them.
  • Printed guide 25, Error code guide (a PDF in the repository's documents folder, on the website under Printed guides and in EA Explorer under Documentation › Printed guides (PDF)). There are now **25 printed guides**; the troubleshooting guide (21) has an Error codes chapter too, and the eax command (15) and Jenkins (16) guides describe eax errors and the new folder.
  • The on-screen help (F1) of Health and Alerts explains the codes.

Fixed

  • eax status no longer reports the self-test's own container as a problem when a test run has finished.
