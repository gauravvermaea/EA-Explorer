Upload files to a project

For: Project Admin, Practising architects

Up to 20 files at a time, 50 MB each.

Why do this

Projects collect material that is not a formal deliverable: workshop photos, inputs from other teams, evidence for a decision, a vendor's proposal. Uploading it to the project keeps it with the work it informs, findable by everyone on the project, instead of scattered across drives and inboxes.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See EA Explorer and the TOGAF Standard.

The goal: Files the project needs are kept with it.

Before you start You need a role on the project (Architect or higher), unless a step says otherwise.

Steps

  1. Open the project, Other documents.
  2. Upload files: choose up to 20 files.
  3. Add a title and description if you like; Upload.
