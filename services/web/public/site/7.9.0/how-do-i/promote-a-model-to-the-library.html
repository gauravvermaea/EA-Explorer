Promote a model to the library

For: Industry model makers, Model Admin

Offer a model to everyone as a reference or template.

Why do this

Promoting makes a library copy of your model, as a draft, to be published after review. It is how good work becomes a starting point for others. See Industry models and the library.

Reference models only help if they are sound and kept up to date, so the library has its own review: promote, request, approve, publish, and withdraw when a reference is past its time.

In TOGAF terms: The Enterprise Continuum: moving from generic and industry architectures to your organisation's own, and back as reusable references. See EA Explorer and the TOGAF Standard.

The goal: Your model is offered to everyone as a reference or template.

Before you start You need the Model Admin role on the model.

Steps

  1. Open Model Admin › Wizards, Promote to the library.
  2. Pick the model; give it a library name and kind (reference or template).
  3. Promote; a Library Admin approves it.
