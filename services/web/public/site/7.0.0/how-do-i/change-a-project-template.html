Change a project template

For: Project Admin

What a template sets up for new projects.

Why do this

A project template decides what a new project of its kind looks like: phases, steps, deliverables, settings. Changing it improves every future project of that kind; projects already started are not touched. See Kinds of architecture project and their goals.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See EA Explorer and the TOGAF Standard.

The goal: New projects of a kind start set up the way your organisation works.

Before you start You need the Library Admin role.

Steps

  1. Open Project Admin › Project templates.
  2. Change a project template: edit its decisions or settings.
  3. Save. Projects already made are not changed.
