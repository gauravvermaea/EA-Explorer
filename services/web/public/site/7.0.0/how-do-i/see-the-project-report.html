See a project's report

For: Practising architects, Project Admin, Executives

Where every deliverable stands, in one page to print or share.

Why do this

The project report summarises a project for its sponsor and steering committee: phases, deliverables, sign-offs and open items, ready to print. See Projects, deliverables and sign-off.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See EA Explorer and the TOGAF Standard.

The goal: Where every deliverable stands, on one page.

Steps

  1. Open the project, Report.
  2. Read where each phase and deliverable stands.
  3. Print or save as PDF.
