AU-change_manager Change manager dashboard

For: Practising architects

The headline view of every report a change manager usually wants, on one page.

What it shows

What it gathers: SR-07 Stakeholder and actor catalogue, SR-22 Impact analysis, VP-23 Project view, VP-25 Implementation and Migration view, TC-02 Stakeholder catalogue, TC-08 Work package and roadmap catalogue, TM-10 Stakeholder and concern matrix, DR-01 Dependencies of an entity, GR-01 Gap analyses, GR-04 Gap resolutions and work packages.

Why it matters

An audience dashboard gathers, on one page, the headline charts of the reports one kind of person usually needs, so they start from what matters to them instead of browsing the whole catalogue.

In TOGAF terms: Stakeholder management: each audience sees the views that address its concerns. See EA Explorer and the TOGAF Standard.

Who it is for

Change manager.

How to use it

Use it as the starting dashboard for the Change manager dashboard: the reports that matter to this audience, together.

How to read it

Each chart is described where it comes from; open the full report from the Reports tab for detail.

Where to find it

Open a model, Reports › Reports, and choose Change manager dashboard; it opens its dashboard for that model. Every chart can be filtered, and most rows have Open to go to the entity in EA Explorer. The same data is in the model's OData feed for your own tools (OData feeds EA Explorer publishes).
