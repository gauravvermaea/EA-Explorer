Run the data quality wizard

For: Model Admin, Practising architects

A guided job to fix a model's findings.

Why do this

The wizard takes the quality findings and walks you through them, so improving a model is a guided job rather than a hunt. See Data quality: why it matters and how it is measured.

Quality is not a one-off clean-up but a habit: rules catch problems as they are saved, the score shows the trend, and owners fix what is theirs. A model people trust is one they keep using.

In TOGAF terms: Supports every ADM phase: the content framework is only useful if its building blocks are complete and correct. See EA Explorer and the TOGAF Standard.

The goal: Missing and wrong values are fixed one entity at a time.

Before you start You need a role on the model that may change content (Architect or higher).

Steps

  1. Open Model Admin › Wizards, Improve data quality.
  2. Pick the findings to fix; fill in the missing values.
  3. Save.
