Make a work package from a gap

For: Project Admin, Practising architects

Turn a gap into a work package in a wave.

Why do this

Work packages group the changes needed to close gaps into units that can be planned, funded and delivered. Making one from a gap keeps the line from the target architecture to the plan. See The ADM: how architecture work is done.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: Phase E, Opportunities and Solutions: work packages. See EA Explorer and the TOGAF Standard.

The goal: A gap becomes a piece of work in a wave.

Before you start You need a role on the project (Architect or higher), unless a step says otherwise.

Steps

  1. Open the gap analysis and a gap.
  2. Work package: name it and its wave; Save.
