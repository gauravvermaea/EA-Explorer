Try the API in the browser

For: Developers, Platform developers

Every API call described, to try with your own sign-in.

Why do this

The API page describes every call, what it takes and what it returns, and lets you try it with your own sign-in. It is the quickest way to get an integration right. See Data in and out: integration.

Systems that talk to EA Explorer need identities of their own, limited to what they do, so their access can be watched and stopped without affecting people. This is part of keeping integration safe as well as useful.

In TOGAF terms: Outside the method: this keeps the repository connected to the systems that feed it, so the Architecture Repository stays current. See EA Explorer and the TOGAF Standard.

The goal: You see and try every API call before writing a script.

Steps

  1. Open https://<your EA Explorer address>/api/docs (or, as a Super Admin, System Admin › Self-test, API harness).
  2. Pick a call; fill in its values.
  3. Try it; copy the call for your script.
