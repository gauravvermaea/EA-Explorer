Tag a model

For: Model Admin, Practising architects

Name this moment, such as Baseline 2026, so you can compare with it or go back to it.

On this page
  • Why do this
  • Steps
  • Related

Why do this

Tags mark moments that matter: a baseline, a submission, before a merge. Projects compare tags, KPIs are kept at them, and you can always go back to one. See Versions, tags and merging.

Nothing in EA Explorer is lost: every change is kept, moments can be named, and work can happen in copies that merge back after review. This is what lets many people change one model without fear.

In TOGAF terms: Phase H and the Architecture Repository: change to the baseline is controlled, recorded and reversible. See EA Explorer and the TOGAF Standard.

The goal: A moment in a model is named, to compare with or return to.

Before you start You need the Committer role or higher.

Steps

  1. Open Model Admin › Wizards, Tag a model now, and pick the model.
  2. Name the tag (e.g. Baseline 2026); Tag.
