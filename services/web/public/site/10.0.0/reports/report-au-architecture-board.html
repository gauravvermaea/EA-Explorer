What it shows

What it gathers: MO Model overview, SR-08 Motivation catalogue, SR-29 Change activity, SR-30 Comparison with the source model, VP-14 Stakeholder view, VP-15 Goal Realization view, VP-17 Motivation view, VP-24 Migration view, VP-26 Gap view, TC-01 Principles catalogue, TC-02 Stakeholder catalogue, TC-03 Driver, goal and outcome catalogue, TC-07 Contract and measure catalogue, TM-11 Plateau and architecture matrix, GR-01 Gap analyses, GR-03 TOGAF gap matrix, QR-01 Data quality across models, QR-04 Failing rules, KR-01 KPI trends.

Why it matters

An audience dashboard gathers, on one page, the headline charts of the reports one kind of person usually needs, so they start from what matters to them instead of browsing the whole catalogue.

In TOGAF terms: Stakeholder management: each audience sees the views that address its concerns. See EA Explorer and the TOGAF Standard.

Who it is for

Architecture board.

How to use it

Use it as the starting dashboard for the Architecture board dashboard: the reports that matter to this audience, together.

How to read it

Each chart is described where it comes from; open the full report from the Reports tab for detail.

Where to find it

Open a model, Reports › Reports, and choose Architecture board dashboard; it opens its dashboard for that model. Every chart can be filtered, and most rows have Open to go to the entity in EA Explorer. The same data is in the model's OData feed for your own tools (OData feeds EA Explorer publishes).
