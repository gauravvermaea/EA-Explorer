Why do this

Key questions keep a project pointed at the people it serves. This guide follows a question from the stakeholder who asks it to the views that answer it and the stakeholder's acceptance. See Stakeholders and key questions.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See EA Explorer and the TOGAF Standard.

The goal: Every stakeholder's question has an answer they accept.

Before you start You need a role on the project.

The ways to do it

  1. The project's Stakeholders tab: add each stakeholder, their position, concerns and how you engage them.
  2. The Key questions tab: + Add a key question, with who asks it.
  3. Link the views that answer it, write the answer, and mark it answered.
  4. The stakeholder accepts the answer (it reaches them as a task).

Each task, one page

  1. Add a stakeholder
  2. Add a project's key questions
  3. Answer a key question
  4. Accept an answer to your question
