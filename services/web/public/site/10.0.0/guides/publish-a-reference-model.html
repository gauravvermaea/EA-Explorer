Publish a reference model to the library

For: Industry model makers, Model Admin

Your finished model in the model library, for everyone to start from.

Why do this

Publishing takes a model from a team's work to an organisation-wide reference, through promotion, a request and an approval. See Industry models and the library.

Reference models only help if they are sound and kept up to date, so the library has its own review: promote, request, approve, publish, and withdraw when a reference is past its time.

In TOGAF terms: The Enterprise Continuum: moving from generic and industry architectures to your organisation's own, and back as reusable references. See EA Explorer and the TOGAF Standard.

The goal: A reference model is in the library for everyone.

Before you start Promoting needs Model Admin on the model; publishing needs the Library Admin role.

The ways to do it

  1. Model Admin › Wizards on the model, Promote to the library: a copy becomes a library model, a draft.
  2. Request publishing.
  3. A Library Admin opens it: Approve and publish, send it back, or reject it.
  4. Published, it is listed in the model library; anyone may copy it or make a child of it.

To take it out later: Withdraw from the library (and restore it).
