EA Explorer 10.0.0: Release 10, scenario planning and game theory through your AI

On this page
  • For everyone
  • Testing
  • Known issues
  • In one paragraph (for the GitHub release)

Release 10 (built 22 Nov 2026; accepted 22 Nov 2026, the owner: "R10 accepted"): your AI can now run a scenario planning study in a project: the futures that could come, the early signs of each, the other players and how they are likely to move, and which option holds up best across all of it. EA Explorer works out the games and the scores itself and shows its working; the project shows the result, read only.

Before updating: take a backup (.\eax backup before-10.0.0). The update runs migrations 0113 to 0115 if you are coming from 8.0.0, or 0115 from 9.0.0. Then .\eax clean-restart and .\eax test smoke.

For everyone

  • The scenario planning wizard (your AI over MCP): ask it to run the scenario planning wizard for a project. It reads the project's documents and models, asks the question the study should answer and which template to use (two uncertainties and four futures, three to five futures, one uncertainty low to high, or players and games only), and works through the driving forces, the futures and their signposts, the players and their games, and the options scored in each future. It suggests; you decide; each part is saved only after your yes.
  • The working is EA Explorer's own, never the AI's guess: each player's best replies, dominant options, the stable outcomes, where everyone would do better by agreeing, mixed strategies (exact, for two players), games in turn worked back from the end, and for the options the best in each future, the most robust and the least regret. Values can be numbers, money or words (with the score you agree).
  • The Scenario planning tab on a project (once it has a study): the recommendation, the forces, the futures, the signposts (those due at this review marked), the options across the futures, the players and their games. Each run is a dated version; earlier ones are a click away. The Project report shows a short section.
  • Signposts at each review: your AI marks each as seen or not; one not marked for 90 days is due again.
  • The sample: Protea build or buy (sample) has a study in two versions.

Testing

  • Every MCP tool is tried in the full test: the tools that change something after a preview must give one (and refuse a wrong confirm token); the others must refuse what is not there. The summary page has an MCP tools card.

Known issues

  • Four Jenkins pipelines (eax-admin's start and maintenance page on, off and clear) can never run (R14.18, Release 14).
  • Certificate mode does not work yet: Release 11, next.

In one paragraph (for the GitHub release)

EA Explorer 10.0.0 adds scenario planning and game theory, run by your AI over MCP in a project: futures and their signposts, the players and their games, and the options tested across them, with the working (best replies, stable outcomes, mixed strategies, robustness and regret) done by EA Explorer itself and shown on a read-only Scenario planning tab, each run kept as a dated version. The full test now tries every MCP tool, with its own card. Take a backup, then .\eax clean-restart.
