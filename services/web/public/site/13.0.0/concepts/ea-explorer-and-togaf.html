EA Explorer and the TOGAF Standard

For: Practising architects, Executives, Project Admin, Model Admin, Industry model makers, System Admin, Developers

Why map them

The TOGAF Standard, from The Open Group, is the most widely used framework for enterprise architecture. It describes a method (the ADM), what that method produces (the content framework), where it is kept (the Architecture Repository), how reuse works (the Enterprise Continuum) and what an architecture practice needs to run (the architecture capability). EA Explorer is built around those ideas, so each part of the tool has a place in the standard. Knowing the place tells you why a task exists and when in the work it matters.

You do not need to know the standard to use EA Explorer; the introduction and The ADM: how architecture work is done give what you need. But if you do know it, this page is your map.

What sits outside the standard

Some parts of EA Explorer are about running the tool rather than the method: sign-in and roles, backups and recovery, secrets, updates, integration and AI. Their pages say so; they serve the practice by keeping the repository safe, current and connected. See Running the installation.
