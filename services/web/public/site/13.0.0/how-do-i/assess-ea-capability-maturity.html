Assess EA capability maturity

For: Project Admin, System Admin

Score the architecture practice and see where it grows.

Why do this

A maturity assessment scores the practice on its elements (governance, method, skills, tools and others) at levels from initial to optimised. Done regularly it shows progress and tells you where investment helps most. See The Architecture Repository.

Some of the most useful architecture knowledge is in people's heads. Surveys and maturity assessments gather it in a form that can be compared over time.

In TOGAF terms: The Preliminary phase and the architecture capability: gathering what people know and judging the maturity of the practice. See EA Explorer and the TOGAF Standard.

The goal: You know how mature the architecture practice is and where to grow it.

Before you start You need the right to manage maturity.

Steps

  1. Open Project Admin › EA capability maturity.
  2. Score each area, with evidence.
  3. Read the result against the last time.
