Take data out with the guide

For: Practising architects, Developers

A step-by-step guide to getting data out, for what you need it for.

Why do this

Data leaves EA Explorer in several ways: Excel to edit and load back, files for another system, live feeds, packages, the API. The guide asks what you need it for and shows the way that fits. See Data in and out: integration.

The architecture is most useful where decisions are made, which is often outside EA Explorer: in reports, spreadsheets, other systems. Data leaves in the shapes those places need, from the same trusted model.

In TOGAF terms: Communicating the architecture: views and data for stakeholders and other systems. See EA Explorer and the TOGAF Standard.

The goal: The right way to get data out, for what you need it for.

Steps

  1. Open the model, Import and export, Take data out.
  2. Choose: edit in Excel and load back, a file for another system, live in Power BI or Excel, a whole-model package, or the API.
  3. Follow the steps.
