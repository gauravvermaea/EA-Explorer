Derive a new project from another

For: Project Admin

A new project that starts from an existing one's content.

Why do this

When a new piece of work follows on from an earlier one (the next phase of a programme, a similar change in another region), deriving it carries over what still applies instead of starting again. See Projects, deliverables and sign-off.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See EA Explorer and the TOGAF Standard.

The goal: A new project starts from an existing one's content.

Before you start You need the Project Admin role.

Steps

  1. Open Project Admin › Wizards, Derive a new project.
  2. Pick the project and what to take.
  3. Name the new project; confirm.
