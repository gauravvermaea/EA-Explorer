Finish the first-run setup

For: System Admin

The first settings of a new installation.

Why do this

A new installation needs a few decisions before people use it: the organisation's name, formats, the first admins. The first-run setup puts them in one place so nothing essential is missed. See Running the installation.

The installation is built to look after itself as far as it can, and to ask before anything risky. These tasks are the decisions it leaves to you: what to run, when, and how far to trust a change.

In TOGAF terms: Outside the method: this keeps the tool that holds the Architecture Repository running. See EA Explorer and the TOGAF Standard.

The goal: A new installation has its essentials in place.

Before you start You need the Super Admin role.

Steps

  1. Open System Admin › Wizards, First-run setup.
  2. Organisation name, formats, first admins.
  3. Finish the setup.
