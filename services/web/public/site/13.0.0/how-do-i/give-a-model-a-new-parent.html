Give a model a new parent

For: Model Admin

Make a model derive from another model.

Why do this

A model's parent decides what its work merges into and whose changes it takes. Giving it a new parent fixes a family that was set up wrongly, or moves a model under a new reference. See Models: what they are and how they relate.

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

In TOGAF terms: The Architecture Landscape in the Architecture Repository: the models at strategic, segment, capability and transition levels. See EA Explorer and the TOGAF Standard.

The goal: A model derives from the parent it belongs with.

Before you start You need the Model Admin role on the model.

Steps

  1. Open Model Admin › Wizards, Detach or reparent, and pick the model.
  2. Choose the new parent; give a reason.
  3. Confirm.
