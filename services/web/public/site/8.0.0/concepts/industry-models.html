Industry models and the library

For: Industry model makers, Model Admin, Practising architects

Reference models that give you a head start, how they are built and published, and how you use them.

  • How you use one

Why start from a reference

Most organisations in an industry share much of their shape: every insurer handles policies, claims and reinsurance; every bank has accounts, payments and lending. An industry model captures that shared shape (capabilities, value streams, information, and a metamodel tuned to the industry), so a new model starts from a sound, complete structure rather than a blank page, and organisations can compare themselves with a common reference.

How they are made and shared

Industry model makers build a model and its metamodel (Build a metamodel in Excel), then promote it to the library, ask for it to be published, and a Library Admin approves it (Publish a reference model to the library). Published models appear in the model library and, with their files, as industry packs (Use an industry pack).

How you use one

Copy it to start your own (Copy a model from the library), or make a child of it so later improvements to the reference can flow to you (Make a child model).
