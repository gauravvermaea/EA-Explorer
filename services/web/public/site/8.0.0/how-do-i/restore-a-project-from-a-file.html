Restore a project from a backup file

For: Project Admin

A project from a file, from this site or another.

Why do this

A project backup file can be restored as a new project or over the one it came from, on this installation or another. It is how projects move between sites and how a lost project comes back. See Backups, restores and disaster recovery.

Recovery is planned before it is needed: what to protect, how often, how to check it, and how far back each kind of restore reaches. EA Explorer takes a backup of now before any restore, so a restore can itself be undone.

In TOGAF terms: Outside the method: this protects the Architecture Repository itself, the record every ADM phase relies on. See EA Explorer and the TOGAF Standard.

The goal: A project from a backup file is back, here or on another installation.

Before you start You need the Project Admin role on the project.

Steps

  1. Open Project Admin › Wizards, Restore a project from a backup file.
  2. Choose the file; as a new project or over itself.
  3. Confirm.
