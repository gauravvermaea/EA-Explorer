Make a gap analysis

For: Project Admin, Practising architects

Compare a baseline with a target and keep the gaps.

On this page
  • Why do this
  • Steps
  • Related

Why do this

Gap analysis is the bridge from target architecture to plan, in ADM phase E: what must be added, changed or removed to get from the baseline to the target. Each gap can become a work package. See The ADM: how architecture work is done.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: Phase E, Opportunities and Solutions (gap analysis is also used in B to D). See EA Explorer and the TOGAF Standard.

The goal: The differences between today and the target are listed, ready to plan.

Before you start You need a role on the project (Architect or higher), unless a step says otherwise.

Steps

  1. Open the project, Gaps.
  2. New gap analysis: pick the baseline and the target (models or tags).
  3. Save as a gap analysis; read the gaps.
