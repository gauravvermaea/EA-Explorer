Archive a model

For: Model Admin

Hide a model from the lists; nothing is lost and it can be reactivated.

Why do this

Over time, models finish their purpose. Archiving keeps the lists short for everyone while keeping the model whole, with its history, in case it is needed again. Reactivating brings it back as it was.

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

In TOGAF terms: The Architecture Landscape in the Architecture Repository: the models at strategic, segment, capability and transition levels. See EA Explorer and the TOGAF Standard.

The goal: A model you no longer use leaves the lists, without losing anything.

Before you start You need the Model Admin role on the model.

Steps

  1. Open Model Admin › Wizards on the model and choose Archive.
  2. Confirm. To bring it back, the same wizard Reactivates it.
