See data quality across every model

For: System Admin, Model Admin

Each model's quality score side by side.

Why do this

Seeing every model's score side by side shows where the repository is strong and where it needs attention, and which owners to support. See Data quality: why it matters and how it is measured.

Quality is not a one-off clean-up but a habit: rules catch problems as they are saved, the score shows the trend, and owners fix what is theirs. A model people trust is one they keep using.

In TOGAF terms: Supports every ADM phase: the content framework is only useful if its building blocks are complete and correct. See EA Explorer and the TOGAF Standard.

The goal: You compare data quality across every model.

Steps

  1. Open System Admin › Running › Data quality.
  2. Sort by score; open a model to fix it.
