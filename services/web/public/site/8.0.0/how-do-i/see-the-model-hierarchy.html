See the model hierarchy

For: Model Admin, Practising architects

Which models derive from which.

Why do this

Model families (roots, library models, children) form a tree. Seeing it shows where a model's metamodel comes from and where its work merges to. See Models: what they are and how they relate.

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

In TOGAF terms: The Architecture Landscape in the Architecture Repository: the models at strategic, segment, capability and transition levels. See EA Explorer and the TOGAF Standard.

The goal: You see which models derive from which.

Steps

  1. Open Model Admin › Model hierarchy.
  2. Read the tree of parents and children.
  3. Click a model to open it.
