Copy a model from the library

For: Model Admin, Industry model makers, Practising architects

Start your own model from a reference or template model in the library.

On this page
  • Why do this
  • Steps
  • Related

Why do this

Library models capture structures many organisations share. Starting from one saves weeks and makes your model comparable with others. A copy is yours to change; if you want later improvements to flow to you, make a child instead. See Industry models and the library.

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

In TOGAF terms: The Architecture Landscape in the Architecture Repository: the models at strategic, segment, capability and transition levels. See EA Explorer and the TOGAF Standard.

The goal: Your model starts from a sound reference instead of a blank page.

Before you start You need the Model Creator role.

Steps

  1. Open Model Admin › Model library (or Architecture Work › Model library).
  2. Open the reference or template model you want.
  3. Choose Start a model from this library model.
  4. Name the new model; choose with or without its data; Create the model.
