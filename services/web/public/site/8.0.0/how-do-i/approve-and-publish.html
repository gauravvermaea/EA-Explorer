Approve and publish a library model

For: Industry model makers

As Library Admin: publish a version, or reject it with a reason.

Why do this

Library models are what others build on, so they are checked before they are published. As Library Admin you are the quality gate: publish what is sound, and send back what is not with a clear reason. See Industry models and the library.

Reference models only help if they are sound and kept up to date, so the library has its own review: promote, request, approve, publish, and withdraw when a reference is past its time.

In TOGAF terms: The Enterprise Continuum: moving from generic and industry architectures to your organisation's own, and back as reusable references. See EA Explorer and the TOGAF Standard.

The goal: A library model is published for everyone, or sent back.

Before you start You need the Library Admin role.

Steps

  1. Open Model Admin › Wizards, Approve and publish.
  2. Open the request; read the changes.
  3. Publish, or reject with a reason (it can be opened again).
