Run a SQL query

For: System Admin, Developers, Platform developers

Read the database with SQL, as your own sign-in allows.

Why do this

Sometimes a question needs the database directly. The SQL page lets an administrator query it with their own sign-in deciding what they may see.

The installation is built to look after itself as far as it can, and to ask before anything risky. These tasks are the decisions it leaves to you: what to run, when, and how far to trust a change.

In TOGAF terms: Outside the method: this keeps the tool that holds the Architecture Repository running. See EA Explorer and the TOGAF Standard.

The goal: You can answer an unusual question straight from the database.

Before you start You need the Super Admin or IT Admin role.

Steps

  1. Open System Admin › SQL.
  2. Pick the database; write the query.
  3. Run; download the result.
