Hand a model over

For: Model Admin

New Model Admins in, old ones out; the model always keeps at least one.

Why do this

People move on. Handing over makes the new Model Admins responsible in one step, with the old ones removed, so a model is never left without someone accountable for it.

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

In TOGAF terms: The Architecture Landscape in the Architecture Repository: the models at strategic, segment, capability and transition levels. See EA Explorer and the TOGAF Standard.

The goal: A model has new owners, and is never left without one.

Before you start You need the Model Admin role on the model.

Steps

  1. Open Model Admin › Wizards on the model and choose Hand over.
  2. Pick the new Model Admins and, if it changes, the owner.
  3. Confirm.
