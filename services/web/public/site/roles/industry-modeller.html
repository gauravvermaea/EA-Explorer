What EA Explorer has for industry model makers

You build reference models and metamodels for an industry: capabilities, value streams, services, processes and a starter landscape that others start from.

Who this is for

People who build reference models for an industry or a domain (banking, insurance, healthcare...) and the metamodels they use, for others to start their own models from. You need the Model Creator role to make models, and Library Admin to publish them in the model library.

How it is put together

  • ArchiMate 4 and the TOGAF 10 content metamodel are built in, with six EA Explorer extensions for TOGAF business architecture (value stream stage, product lifecycle stage, business scenario, control, contract, measure), each marked as an extension.
  • A metamodel workbook has one sheet each for the model's details, domains, pick lists, attributes, types, type attributes, relationship types, allowed relationships (with multiplicity) and rules. It is the quickest way to build or review a whole metamodel.
  • A reference model is an ordinary model marked as a reference and published in the library. Others copy it, or make a child of it so later changes can be pushed down to theirs.
  • Packs are files kept with EA Explorer and loaded into Documents at start-up, so every installation has them.
