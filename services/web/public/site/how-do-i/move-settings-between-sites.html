Copy settings to another site

For: System Admin

Export the admin settings to a file, and import them on another site, with every difference shown first.

On this page
  • Steps
  • Check it worked
  • If something goes wrong
  • Related

Before you start You need the Super Admin role on both sites.

Steps

  1. On the first site: System Admin › Settings › Settings import and export. Tick the parts (for example system settings, branding, alerts, schedules) and Export to a file, or Put on git.
  2. On the other site, the same page: Choose a settings file (or From git).
  3. Every difference is shown: the value here and in the file. Nothing changes yet.
  4. Tick what to take, then Take. A safety copy of the settings there is kept first, and each change goes in the audit trail.

On the machine: eax settings export <file> and eax settings import <file> (it shows the differences; add --yes to take them).

Check it worked

The page says how many were taken. The safety copy is listed below.

If something goes wrong

  • Undo on the safety copy puts the settings back as they were.
  • Passwords, keys, certificates, people and content never travel in the file.
