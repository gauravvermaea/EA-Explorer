Receive webhooks

For: Developers, System Admin

Signed messages to your system when something happens in EA Explorer.

Before you start An IT Admin or Super Admin adds the webhook.

Steps

  1. System Admin › Settings › System settings, Webhooks: Add webhook with your address and the kinds it receives (commits, metamodel changes, requests, models; none ticked means all).
  2. EA Explorer sends each event as JSON to your address, signed: check the X-EAX-Signature header (HMAC-SHA256 of the body with the webhook's secret) before trusting it.
  3. Each delivery and its answer is kept, so failed ones can be seen.
