Create a model

For: Model Admin, Industry model makers

A new model: blank on a metamodel, a copy of another, a child that merges back, or started from a library model.

On this page
  • Steps
  • Check it worked
  • Related

Before you start You need the Model Creator role to make a model from nothing, or Model Admin on the model you copy.

Steps

  1. Open Model Admin › Wizards, then choose:
    • New model: blank, on the metamodel you choose (ArchiMate 4, TOGAF 10, an industry's, or your own).
    • Copy a model from the library: start from a reference or template model.
    • Copy with the parent-child link: a child; its work merges back, and the parent's metamodel changes flow down.
    • Copy without the link: a separate copy, with or without the data.
  2. Give it a name and say who looks after it. Every wizard asks before it changes anything.
  3. Open the new model and give people their roles on its People tab.

Check it worked

The model is listed on Model Admin › Models and in Model hierarchy, under its parent if it has one.
