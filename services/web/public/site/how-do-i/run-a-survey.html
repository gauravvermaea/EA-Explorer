Run a survey or a maturity assessment

For: Project Admin

Questions to stakeholders through their task list, and EA capability maturity assessed and scored.

Before you start Surveys need the Project Admin role; maturity assessments need a Super Admin.

Steps

  1. Project Admin › Surveys and maturity › Surveys: a designer with sections, eight kinds of question and conditions.
  2. Send it to people, global roles, models or projects: it reaches them in their task list and by a link, with reminders and a closing date; it can be anonymous.
  3. Results by question, downloadable as Excel. Answers never change a model.
  4. EA capability maturity: assessments on nine architecture elements and six levels, scored per element and overall, with targets and gaps, and a trend over assessments.
