Webhooks

For: Developers, System Admin

EA Explorer tells your system the moment something happens, signed so you know it is genuine.

On this page

Why webhooks

Polling an API to see whether anything changed is slow and wasteful. A webhook turns it round: EA Explorer calls your address when something happens (a notification in a category you choose), so your system can react at once: open a ticket, post to a channel, start a job.

What you receive

One plain JSON body per event, with headers:

HeaderWhat it is
X-EAX-EventThe kind of event
X-EAX-DeliveryThis delivery's id
X-EAX-Signaturesha256= and the HMAC-SHA256 of the body with the webhook's shared secret

Check the signature with the shared secret before trusting the body. A receiver that fails is retried with back-off, up to eight times over about two hours, and every delivery is logged.

Setting one up

System Admins add the address, the categories and the shared secret on System Admin › System settings › Webhooks. See Receive webhooks.
