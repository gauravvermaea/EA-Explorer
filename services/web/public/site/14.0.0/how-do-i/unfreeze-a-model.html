Unfreeze a model

For: System Admin

Let a frozen model change again.

Why do this

Freezing is meant to be permanent, so only a Super Admin can unfreeze, with a reason. It is for the rare case where a frozen model must be corrected.

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

In TOGAF terms: The Architecture Landscape in the Architecture Repository: the models at strategic, segment, capability and transition levels. See EA Explorer and the TOGAF Standard.

The goal: A frozen model can change again.

Before you start You need the Super Admin role.

Steps

  1. Open Model Admin › Wizards, Freeze or unfreeze, and pick the model.
  2. Unfreeze; give a reason.
