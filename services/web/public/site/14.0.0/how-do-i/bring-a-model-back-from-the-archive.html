Bring a model back from the archive

For: Model Admin

A model moved to the archive database, back in the working one.

Why do this

Moving a model to the archive database takes it out of everyday work while keeping it whole. Bringing it back restores it with its history, for when an old programme restarts or an audit needs it.

A model's life has stages: started, worked on, copied or split, handed over, locked or frozen at key moments, archived when done. Each stage has its wizard, and each asks before it changes anything.

In TOGAF terms: The Architecture Landscape in the Architecture Repository: the models at strategic, segment, capability and transition levels. See EA Explorer and the TOGAF Standard.

The goal: A model moved to the archive database is in use again.

Before you start You need the Model Admin role on the model.

Steps

  1. Open Model Admin › Archive.
  2. Find the model; Bring it back.
  3. It returns whole, with its history.
