Upload your own document template

For: Project Admin

A template of your own for a deliverable.

Why do this

Many organisations have their own templates for deliverables, with their branding, sections and approvals. Uploading them puts them in the template library beside the standard ones, so every project uses the organisation's agreed shape without hunting for the latest version.

A project carries one pass of the ADM from vision to sign-off. Each task here is one of the steps along that route, and the project keeps them together so the whole story can be read later.

In TOGAF terms: The ADM itself: the phases, steps, deliverables and sign-offs of an architecture project. See EA Explorer and the TOGAF Standard.

The goal: Your own template is available to projects.

Before you start You need the Library Admin role.

Steps

  1. Open Project Admin › Project content template library.
  2. Upload a template: choose the file.
  3. Give it its deliverable; projects can add it.
