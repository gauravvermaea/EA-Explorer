VP-08 Application Usage view

For: Practising architects

The model through the Application Usage view: which applications the business uses and for what. As a catalog, a matrix, a network and a heat map.

What it shows

From the ArchiMate 4 Specification, Appendix C (The Open Group).

Its concerns: Which applications the business uses and for what. For: Enterprise, Process, and Application Architects, Operational Managers. Purpose: Designing, deciding.

Element types shown: Business Actor, Role, Collaboration, Process, Function, Event, Business Object, Application Component, Application Interface, Service, Data Object, Grouping.

Relationships shown: Composition, Aggregation, Assignment, Realization, Serving, Access, Influence, Association, Triggering, Flow, Specialization. The heat map colours by Lifecycle.

Why it matters

Views from the ArchiMate 4 Specification each serve a set of stakeholders and concerns, by showing only the element and relationship types that matter to them. EA Explorer shows each one from your model as a catalogue, a matrix, a network and a heat map.

In TOGAF terms: An architecture view, addressing stakeholders' concerns; it usually supports the TOGAF artifact named below. See EA Explorer and the TOGAF Standard.

Who it is for

Application owner, Process owner, Application architect.

How to use it

Use it to look at the model the way the Application Usage view's stakeholders need: only the element and relationship types that matter to their concerns.

How to read it

The catalog lists the elements, the relationships table shows how they connect, and the heat map colours elements by the view's attribute. Missing elements of a type mean that part is not modelled yet.

Where to find it

Open a model, Reports › Reports, and choose Application Usage view; it opens its dashboard for that model. Every chart can be filtered, and most rows have Open to go to the entity in EA Explorer. The same data is in the model's OData feed for your own tools (OData feeds EA Explorer publishes).

For developers and report builders: it reads rpt.vp_elements; its dashboard is eax-vp08.
